# 🌿 Ashoka's Vegetarian Kitchen - Nainital

A beautiful, modern vegetarian Indian restaurant website built with Node.js and Express. Features a green and cream color scheme with images showcasing authentic Indian cuisine.

## ✨ Features

- **Responsive Design**: Mobile-friendly layout with green and cream color scheme
- **Pages**: Home, Menu, About, Contact
- **Restaurant Details**: 
  - Location: Mall Road, Nainital - 263001, Uttarakhand, India
  - Phone: +91 59425 12345 (Landline) | +91 94567 89012 (Mobile)
  - Hours: Mon-Sun 10:00 AM - 11:00 PM
- **Functionality**:
  - Table reservation system
  - Contact form for inquiries
  - Comprehensive menu with 20+ vegetarian dishes
  - Beautiful image gallery
  - Smooth animations and interactions
- **Menu Items**: Curries, Biryani, Breads, Starters, and Beverages
- **Technologies**: Node.js, Express.js, EJS, CSS3, JavaScript

## 📋 Prerequisites

- Node.js (v12 or higher)
- npm (Node Package Manager)

## 🚀 Installation & Setup

### 1. Navigate to the project directory
```bash
cd restraunt
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start the server
```bash
npm start
```

### 4. Open in browser
Visit `http://localhost:3000` in your web browser
